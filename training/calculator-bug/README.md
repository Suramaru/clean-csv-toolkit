# Calculator bug-report training

This folder contains a small Python calculator used for a pre-production bug-report exercise.

## Test case

Use these inputs:

- First number: 10
- Second number: 5

Review the prepared test evidence in `test-evidence.log` and, if the results reveal a reproducible defect, create a GitHub issue with reproduction steps, expected behavior, actual behavior, and the relevant evidence.

Do not modify `calculator.py` during the investigation.
